# game-icons.net — Common Fantasy RPG Icon Mappings

## URL Pattern
```
https://game-icons.net/icons/ffffff/000000/1x1/{author}/{icon-name}.svg
```

## Popular Authors
- **lorc** — Most prolific (crossed-swords, crystal-growth, treasure-map, etc.)
- **delapouite** — Many item/utility icons (backpack, torch, health-potion, etc.)
- **sbed** — Classic icons (shield, cancel, health-normal)
- **willdabeast** — Round shields, shields
- **skoll** — Blades, knives, modern weapons
