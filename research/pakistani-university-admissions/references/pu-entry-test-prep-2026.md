## Physics — High-Frequency Topics (2019-2024)

### Measurements & Dimensions (EVERY paper)
- Angular momentum: [ML²T⁻¹] (L = mvr)
- Force: [MLT⁻²] (F = ma)
- Energy: [ML²T⁻²] (E = mc², KE = ½mv²)
- Power: [ML²T⁻³] (P = W/t)
- Viscosity: [ML⁻¹T⁻¹] (η = F/(A·dv/dx))
- % uncertainty: In KE = ½mv², %ΔKE = %Δm + 2×%Δv
- 1 km² = 10⁶ m²
- SI units: candela (luminous), Pascal (pressure)

### Motion & Force
- v = u + at, v² = u² + 2as, s = ut + ½at²
- Slope of v-t = acceleration. Area under v-t = displacement
- F = dp/dt (Newton's 2nd in general form)
- Conservation of linear momentum from Newton's 3rd law
- Projectile: aₓ = 0 (constant horizontal v), aᵧ = -g
- Free fall: constant g, independent of mass
- Terminal velocity: drag = gravity

### Work, Energy & Power
- KE = ½mv², PE = mgh, W = Fs·cosθ
- Power = W/t = Fv. Unit: watt (J/s)
- Impulse J = FΔt = Δp. Unit: N·s
- Work = 0 when force ⟂ displacement (centripetal force)
- Conservation of energy: ΔE_total = 0 in isolated system

### Circular Motion & Gravitation
- a_c = v²/r = ω²r, F_c = mv²/r
- Torque τ = r×F = Iα (rotational analogue of force)
- Angular momentum L = mvr = Iω
- Centripetal force does ZERO work (always ⟂ to motion)
- Escape velocity = 11.2 km/s (Earth)
- Geostationary orbit: ~36,000 km
- GPE = mgh (near Earth)

### SHM, Waves & Sound
- F = -kx (Hooke's law), restoring force ∝ displacement
- Pendulum T = 2π√(L/g) — independent of mass/amplitude
- Resonance at natural frequency
- Sound: longitudinal mechanical wave
- Doppler: observed frequency changes with relative motion
- Standing waves: incident + reflected same wave
- f = 1/T

### Thermodynamics
- Zeroth law → temperature concept
- First law ΔU = Q + W (energy conservation)
- Carnot efficiency η = 1 - T_c/T_h
- Entropy ΔS ≥ 0 (isolated system)
- Absolute zero = -273.15°C
- Isothermal: T constant, ΔU = 0

### Electrostatics
- F = kq₁q₂/r² (Coulomb's law, inverse square)
- E = F/q (unit: N/C = V/m)
- Work on equipotential surface = 0 (W = qΔV)
- Capacitance C = ε₀A/d

### Current Electricity
- V = IR (Ohm's law)
- KVL: ΣEMF = ΣIR or ΣV = 0 around loop
- R = ρL/A (∝ length, ∝ 1/area)
- Wheatstone bridge: measure unknown resistance
- Parallel resistors: 1/R = 1/R₁ + 1/R₂ + ...

### Magnetism & Induction
- F = BIL·sinθ (force on current wire)
- B_solenoid = μ₀nI (uniform inside)
- Faraday: ε = -dΦ/dt
- Lenz's law: induced current opposes change (energy conservation)
- Self-inductance ε = -L·dI/dt (opposes CHANGE in current)
- Magnetic flux unit: Weber (Wb = T·m²)

### AC Circuits
- V_rms = V₀/√2, I_rms = I₀/√2
- Pure inductor: V LEADS I by 90° (ELI)
- Pure capacitor: I LEADS V by 90° (ICE)
- Transformer: mutual induction, V_s/V_p = N_s/N_p
- Eddy currents reduced by laminating core
- Full-wave rectifier: f_out = 2f_in

### Optics
- Critical angle: sin C = 1/n
- TIR: denser→rarer AND θ > C
- Young's double slit: interference (wave nature of light)
- Speed of light c = 3×10⁸ m/s

### Modern Physics
- Photoelectric: KE_max = hf - φ (or hf = φ + KE)
- de Broglie: λ = h/p = h/(mv)
- Bohr hydrogen: E_n = -13.6/n² eV, ground = -13.6 eV
- X-rays: fast electrons hit metal target
- E = mc² (Einstein)

### Nuclear Physics
- Mass number A = Z + N (protons + neutrons)
- α = He-4 nucleus (A-4, Z-2), β⁻ (Z+1, A same), γ (excited nucleus)
- Half-life: N = N₀(½)^(t/T)
- Fission: heavy splits (U-235), Fusion: light joins
- Fe-56 has highest binding energy per nucleon

### Electronics
- AND: output 1 only when ALL inputs 1
- NAND: universal gate (NOT-AND)
- Transistor: amplifier (active) + switch (cutoff/saturation)
- Diode: forward bias → current flows, reverse → blocks

## Computer Science Quick Facts

**Hardware:** Physical parts. CPU = fetch-decode-execute. ALU = arithmetic/logic.
**Software:** 3 types — System (OS), Application (Word), Utility (antivirus).
**Memory:** RAM = volatile, ROM = non-volatile. 1 byte = 8 bits.
**Keyboard:** QWERTY. Shift+F3 = change case. Ctrl+S = save. Ctrl+C = copy.
**Excel:** =SUM() adds, =AVERAGE() mean, =MAX()/MIN(). Formulas start with =.
**Ports:** HTTP=80, HTTPS=443, FTP=21, SMTP=25.
**Network:** LAN=local, WAN=wide. Topologies: Star, Bus, Ring, Mesh.
**DB:** Primary key = unique per row. DBMS = Database Management System.
**Binary:** 1+1=10. Computer speaks binary (0s and 1s) directly.
**Internet:** Modem connects to internet. URL = Uniform Resource Locator.
**Hard copy:** Printer. Soft copy: Monitor.

## Mathematics Quick Facts

**Complex numbers:** |Z| = √(a²+b²), arg = tan⁻¹(b/a). Conjugate = a-bi.
Multiplicative inverse of a+bi = (a-bi)/(a²+b²). i⁻¹ = -i.

**Matrices:** det([[a,b],[c,d]]) = ad-bc. A⁻¹ = (1/det) × [[d,-b],[-c,a]].

**Trig:** sin²θ + cos²θ = 1, tanθ = sinθ/cosθ, sin(π/2-θ) = cosθ.

**Quadratic:** x = [-b ± √(b²-4ac)]/2a.

**AP:** aₙ = a+(n-1)d, Sₙ = n/2(2a+(n-1)d). Sum of 1st n naturals = n(n+1)/2.

**Probability:** P(E) = favorable/total. P(A∪B) = P(A)+P(B)-P(A∩B).

## Quant Reasoning Tricks

| Problem type | Method |
|-------------|--------|
| Consecutive numbers sum S | Middle = S/3, numbers = middle-1, middle, middle+1 |
| Missing value from averages | total = avg × n, subtract known groups |
| Ratio + average | k = total/sum_of_ratios, each part = k × its ratio |
| Avg of 1st n naturals | (n+1)/2 |
| Discount % | Pay = price × (1 - %/100) |
| Work problem | workers × days = constant |
